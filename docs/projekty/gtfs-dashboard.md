# GTFS Dashboard

GTFS Dashboard to przeglądarka danych z pipeline'u [easy-GTFS-RT](easy-gtfs-rt.md):
zrealizowanych rozkładów jazdy zrekonstruowanych z danych GTFS-RT, a nie rozkładów
planowych. Nawigacja działa według schematu miasto → miesiąc → dzień → szczegóły, z
wykresami odchyleń od rozkładu i linkami do pobrania danych źródłowych. Dashboard zbiera
dane dla kilkunastu miast.

[Zobacz dashboard →](https://gisboost.github.io/gtfs-dashboard/)
